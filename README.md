# Marvel Information portal

## Описание
`Marvel Information portal` - это проект на React, посвященный вселенной Marvel.\
Портал содержит информацию, полученную со строннего API: герои и комиксы, их краткое описание и изображения. Также доступен поиск по персонажам.


## Технологии
- SCSS
- JavaScirpt
- React.js
- React Router DOM
- Formik & Yup
- Redux Toolkit

## Установка
1. Клонируйте репозиторий:
```bash
git clone https://github.com/ttseva/marvel-info-portal.git
cd marvel-info-portal
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение локально:
```bash
npm start
```

После запуска:
- Главная страница: `http://localhost:3000/`
- Страница комиксов: `http://localhost:3000/comics`
